# UI Screenshots Asset Directory

This directory stores visual interface screenshots, UI recordings, and dashboard captures for **Linus Linus's 7 Enterprise Production Systems**.

## Recommended File Format & Resolution
- **Format:** `.png`, `.jpg`, `.jpeg`, or `.webp`
- **Desktop Windows Suites:** `1920x1080` or `1600x900`
- **Web Applications:** `1920x1080` (Desktop viewport) or `390x844` (Mobile viewport)
