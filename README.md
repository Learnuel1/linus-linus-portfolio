## 🌐 GitHub Pages Deployment Instructions

This repository is configured for automated deployment to **GitHub Pages** via GitHub Actions:

1. Push this repository to GitHub:
   ```bash
   git remote add origin https://github.com/Learnuel1/linus-linus-portfolio.git
   git push -u origin main
   ```
2. In the GitHub repository, navigate to **Settings > Pages**:
   - Under **Build and deployment > Source**, select **GitHub Actions** (or select **Deploy from a branch** > branch: `main` > folder: `/ (root)`).
3. Your portfolio will be live at:
   ```
   https://Learnuel1.github.io/linus-linus-portfolio/
   ```
